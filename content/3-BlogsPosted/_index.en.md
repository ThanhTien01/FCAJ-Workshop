During my internship, I wrote and published 03 blog posts in the [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj) community. The articles focus on sharing knowledge, lessons learned, and practical experiences in applying AWS services and solutions during the internship.

### [Blog 1 - Best Practices for Right-Sizing Amazon EC2](3.1-Blog1/)
This blog introduces Right Sizing for Amazon EC2, a method that helps choose the appropriate EC2 configuration based on real workload needs. The content focuses on optimization practices such as examining and measuring resource usage, selecting suitable instances, grouping similar workloads, and combining Savings Plans/Reserved Instances to reduce AWS costs.

### [Blog 2 - Optimizing Docker Build Time on AWS CodeBuild with Amazon ECR](3.2-Blog2/)
This blog explains how to optimize Docker image build time on AWS CodeBuild using Amazon ECR as a remote cache. During Docker image builds, some steps can take a long time if they must be repeated on every build. Using a remote cache allows Docker to reuse previously built layers, reducing build time and improving CI/CD efficiency. The article also explains how Docker, AWS CodeBuild, and Amazon ECR work together to streamline the Docker build process in a simple and effective way.

### [Blog 3 - Automating Budget Management Across Multi-Account Environments](3.3-Blog3/)
This blog introduces how to automate budget management in an AWS Multi-Account environment. As the number of AWS accounts increases, manually monitoring and controlling costs becomes more difficult and time-consuming. The article explains how to use AWS Budgets together with AWS Organizations to set budgets, track costs, and send automatic alerts for multiple AWS accounts. This helps organizations control costs more effectively and reduce manual administrative effort.
