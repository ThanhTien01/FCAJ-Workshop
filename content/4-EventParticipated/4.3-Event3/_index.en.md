# Summary Report: “Agent Forge - Deepdive Day 2”

### Event Objectives

- Learn advanced features of Amazon Bedrock AgentCore.
- Focus on personalizing AI Agent behavior, evaluating performance, monitoring operations, and optimizing agents.
- Understand how to take an AI Agent from a basic deployment to a system that operates stably, is evaluated, and continuously improved.

### Speaker List

- **Nghia Tran** - Agentic SA
- **Anh Pham** - Cloud Consultant G - AsiaPacific Vietnam

### Highlights

#### 1. Advanced Amazon Bedrock AgentCore

In the theoretical session, I learned about the advanced features of AgentCore, including:
- **Memory**: How to store and use information from previous interactions to build personalized AI Agent behavior.
- **Evaluations**: How to assess the quality and performance of an agent based on appropriate criteria.
- **Observability**: How to monitor and observe agent activity and performance.
- **Tools**: How to extend an agent through external tools.
- **Payments**: Components related to integration and handling payment-related activities.
- **Optimization**: Methods to optimize agent performance.
- **Policy**: How to apply policies to control agent behavior and operation.

#### 2. Hands-on Lab

In the practical session, I performed the following activities:

- Added Memory so the agent could remember information and create personalized behavior.
- Explored Agent Observability features to monitor agent activity.
- Used AgentCore Evaluations to measure and assess agent performance.
- Explored AgentCore Harness to support AI Agent testing and evaluation.

### Outcomes and Value

- Through the event, I gained a deeper understanding of personalizing, evaluating, monitoring, and optimizing AI Agents. In particular, I realized that building an AI Agent is not limited to deploying the agent; it also requires mechanisms for memory management, quality assessment, and operational monitoring.
- The hands-on section gave me practical experience configuring Memory, Observability, and Evaluations, as well as familiarizing myself with AgentCore Harness. These insights improve my ability to research and implement Generative AI and AI Agent solutions on AWS, while also adding knowledge about operating and optimizing AI systems in real-world environments.
