# Summary Report: “Agent Forge - Deepdive Day 1”

### Event Objectives

- The event aimed to help attendees understand the foundational concepts of Amazon Bedrock AgentCore.
- Practice building and deploying an AI Agent.
- The workshop was designed to help participants learn how AgentCore supports building agents that can connect to external tools, knowledge bases, and user authentication systems.

### Speaker List

- **Nghia Tran** - Agentic SA
- **Anh Pham** - Cloud Consultant G - AsiaPacific Vietnam

### Highlights

#### 1. Introduction to Amazon Bedrock AgentCore

In the first part of the workshop, I received an overview of Amazon Bedrock AgentCore and the role this platform plays in building, deploying, and operating AI Agents.

The main topics included:
- Introduction to the workshop and program objectives.
- Overview of Amazon Bedrock AgentCore.
- Understanding AgentCore Runtime and how to deploy agents.
- Learning about AgentCore Gateway and the ability to connect agents with external tools and services.
- Learning about AgentCore Identity and the role of identity and access management in AI Agent systems.

#### 2. Hands-on Lab

After the theory section, I directly practiced building an AI Agent using AgentCore.

The main activities included:
- Deploying a basic agent on AgentCore.
- Connecting the agent with external tools and knowledge bases.
- Building a Web UI to interact with the agent.
- Integrating Amazon Cognito to authenticate users when accessing the application.

### Outcomes and Value

- Through the workshop, I had the opportunity to learn practically about Amazon Bedrock AgentCore and the process of building an AI Agent from deployment to integration with external components. I gained a clearer understanding of the roles of Runtime, Gateway, and Identity in the AgentCore architecture.
- The hands-on section helped me reinforce knowledge by directly deploying an agent, connecting tools and knowledge bases, and building a Web interface integrated with Amazon Cognito. As a result, I improved my practical skills with AWS services and gained foundational knowledge to explore Generative AI and AI Agent applications in later phases of the internship.
